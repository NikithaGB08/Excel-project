# E-commerce Sales Analytics

An Excel project analyzing e-commerce sales, profit, customer, product, and regional performance.

## Project overview

This workbook uses PivotTables, charts, key performance indicators (KPIs), and an interactive dashboard to explore sales data and summarize business performance.

## Skills demonstrated

- Data analysis and summarization in Microsoft Excel
- PivotTables and charts
- KPI reporting
- Interactive dashboard design

## Files

- Excel workbook containing the sales analytics project

## How to view

Download the Excel workbook from this repository and open it in Microsoft Excel to explore the analysis and dashboard.
